CurseStone: servidor de código abierto para Minecraft PE 0.15.x

CurseStone es un software de servidor de código abierto para Minecraft: Pocket Edition 0.15.x (protocolo 84), escrito en C y C++20 y enfocado en el alto rendimiento. Tiene un núcleo en C puro para red, NBT y datos de chunks, con la lógica del juego en C++20.

Es una opción para ejecutar un servidor MCPE pequeño que puedes leer, compilar y modificar, con documentación y desarrollo abiertos en GitHub.

Características principales

  • Plugins en Lua: Lua 5.4 integrado en el binario, sin instalar nada más.
  • Dos formatos de mundo: anvil (por defecto) y leveldb.
  • Generación de terreno: biomas, ruido y populators incluidos.
  • Diagnósticos integrados: profiler en tiempo de ejecución y volcados de fallos.
  • Multiplataforma: Linux, macOS, Windows y Android (Termux).

Documentación

CurseStone cuenta con dos documentaciones: una guía inicial en Read the Docs y la documentación completa del software.

Desarrollo y comunidad

El código fuente está en el repositorio de GitHub (rama stable). Puedes abrir issues, enviar pull requests y unirte a la comunidad en Discord o seguir el proyecto en YouTube.
