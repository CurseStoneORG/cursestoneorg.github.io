CurseStone v1.0.2 Beta Release

Changes since Beta v1.0.1.5.

Added

  • Nether portals and dimension travel between the Overworld and Nether, including portal activation, persistent portal linking, coordinate conversion, and dimension switching.
  • Multiworld support with world loading, unloading, lookup, independent ticking, autosaving, and shutdown saving.
  • Nether terrain generation with bedrock boundaries, glowstone clusters, and fire placement.
  • Vanilla beds with two-part placement, sleeping animations, player synchronization, bed-based spawn points, and nighttime skipping when all players in a world are asleep.
  • Hunger and food systems with saturation, exhaustion, regeneration, starvation, and persistent player data.
  • New foods: baked potato, beetroot, beetroot soup, raw and cooked fish, raw and cooked mutton, raw and cooked rabbit, rabbit stew, cookie, pumpkin pie, golden carrot, enchanted golden apple, rotten flesh, and spider eye.
  • Drinkable potions, throwable splash potions, projectile collisions, shatter effects, and area-based effect application.
  • 23 status effects: Speed, Slowness, Haste, Mining Fatigue, Strength, Instant Health, Instant Damage, Jump Boost, Nausea, Regeneration, Resistance, Fire Resistance, Water Breathing, Invisibility, Blindness, Night Vision, Hunger, Weakness, Poison, Wither, Health Boost, Absorption, and Saturation.
  • Milk buckets that remove active status effects and leave an empty bucket.
  • Bow drawing, release handling, arrow flight, projectile collisions, pickup, and despawning.
  • Falling-block physics for sand, gravel, and anvils, including landing behavior and block restoration.
  • Custom item names and NBT preservation across inventories, equipment, containers, and dropped-item entities.
  • Expanded Lua plugin API with world management, player manipulation, plugin resource access, and additional player, entity, bed, door, and interaction events.
  • Lua command overrides with automatic restoration of built-in commands when plugins unload.
  • Lua plugin execution limits, per-call time limits, and automatic disabling after consecutive errors.
  • Added /kill <player> and the operator-only /status command with TPS, memory, uptime, player count, plugin count, and world diagnostics.
  • First-run setup wizard for server settings, world configuration, and game defaults.
  • Embedded default configuration templates in the executable.
  • Added start.sh for Linux and Termux and start.bat for Windows, with automatic restarts after unexpected exits.
  • Windows x86-64 build support and platform-specific release archives.
  • Doxygen documentation generation and automated publishing.
  • Development guidelines, code-formatting rules, and project documentation.

Changed

  • Separated basic configuration in server.properties from advanced configuration in cursestone.yml.
  • Moved plugin data storage to the server-root data_pl/ directory.
  • Standardized the server and plugin API version through CURSESTONE_API, set to 1.0.2.
  • Improved player damage handling for creative mode, environmental damage, armor, resistance, strength, weakness, and absorption.
  • Improved multiplayer synchronization for health, hunger, food consumption, equipment, item use, bows, arrows, knockback, death, respawning, and item pickup.
  • Improved door sounds, bed synchronization, and nighttime handling.
  • Improved player NBT persistence for health, hunger, saturation, exhaustion, active effects, and bed spawn positions.
  • Optimized incremental chunk autosaving with a shared per-tick budget across loaded worlds.
  • Added UTF-16 support and improved normalization when reading ops.txt.
  • Improved item-stack validation and maximum stack-size enforcement.
  • Improved Windows portability through MSVC compatibility fixes, POSIX shims, threading support, and static zlib and LevelDB linking.
  • Standardized source formatting and comments, reorganized source files, and removed obsolete empty source stubs and outdated test utilities.

Fixed

  • Fixed Nether portal frame detection, ignition, metadata, portal linking, and dimension travel.
  • Fixed beds and doors becoming ghost blocks or failing to synchronize correctly.
  • Fixed bed sleeping animations and sleep data not being delivered correctly to the local player.
  • Fixed chunk streaming issues that prevented the full view distance from loading correctly.
  • Fixed login and spawn packet ordering to improve initial chunk delivery.
  • Fixed falling blocks using an incorrect network entity ID that prevented proper client rendering.
  • Fixed fire interactions, environmental damage, and fall-damage handling.
  • Fixed splash potion rendering, shatter effects, and status-effect delivery on MCPE 0.15.10.
  • Fixed food consumption, milk usage, health updates, and hunger synchronization in multiplayer.
  • Fixed bow animations, arrow spawning, projectile movement, and release behavior in multiplayer.
  • Fixed dropped items remaining visible after pickup and improved item synchronization between players.
  • Fixed inventory duplication, invalid stack sizes, and merging of items with different NBT data.
  • Fixed custom item names and NBT data being lost during inventory, container, equipment, and death-drop operations.
  • Fixed player death and respawn handling.
  • Fixed chest block-event packet handling.
  • Fixed plugin event bindings and message handling.
  • Fixed operator-list parsing on Android, including UTF-16 files and inconsistent entry formatting.
  • Fixed Windows compilation and release packaging issues involving MSVC, POSIX compatibility, ssize_t, math constants, logger threading, and artifact paths.
  • Fixed startup configuration defaults and behavior when configuration files are missing.

Notes

  • Compared against Beta v1.0.1.5.
  • Target client: Minecraft: Pocket Edition 0.15.x.
  • Network protocol: 84.
  • The project remains server software and does not implement every vanilla Minecraft mechanic.
  • Some features may require additional in-game testing to verify complete client compatibility.
